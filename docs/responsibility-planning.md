# Planning: Human & AI Responsibilities in This Project

Legend: **[H]** human-led · **[AI]** AI-led · **[H+AI]** human-led, AI-assisted

## 1. Requirements & Ideation

- [ ] **[H]** Clarify requirements
- [ ] **[H]** Come up with the idea
- [ ] **[AI]** Draft requirements design based on the idea and clarified requirements
- [ ] **[H]** Double-check requirements

## 2. Database Design

- [ ] **[H]** Design the database
- [ ] **[AI]** Double-check the design
- [ ] **[H]** Compare pros/cons and choose the best version
- [ ] **[H]** Implement the database and build a POC to validate it matches the business logic
- [ ] **[H+AI]** Double-check with AI to validate design performance and query efficiency

## 3. High-Level Architecture

- [ ] **[H]** Design high-level architecture (infra, services, database) for HA, scalability, data consistency, and failover handling
- [ ] **[AI]** Double-check the architecture idea
- [ ] **[H]** Compare options and choose

## 4. Tech Stack

- [ ] **[H+AI]** Research programming language and framework (tech stack) with AI
- [ ] **[H]** Decide on the tech stack

## 5. Planning

- [ ] **[H]** Estimate the timeline based on final requirements
- [ ] **[H]** Plan task execution order
- [ ] **[H]** Define conventions and coding rules

## 6. Implementation

- [ ] **[H]** Implement code
- [ ] **[AI]** Refactor and double-check code

## 7. Testing

- [ ] **[H]** Testing
- [ ] **[AI]** Expose the AI (API/service)

## 8. Frontend & Integration

- [ ] **[AI]** Create the frontend for a convenient demo
- [ ] **[H]** Integrate with the frontend

## 9. Performance & QA

- [ ] **[AI]** Generate large volumes of test data
- [ ] **[H]** Benchmark, load test, performance test, etc.

## 10. Documentation & Demo

- [ ] **[H+AI]** Rewrite documentation
- [ ] **[AI]** Produce the demo video
